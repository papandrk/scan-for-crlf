# scan-for-crlf

Used to search for CRLF sequences in Git repos and notify the user so they can fix them, if they are so inclined.

## How to use

Copy-paste either the **scan_crlf.py** file or the **scan_crlf_v2.py** file to you git repo and run the script in you terminal (Bash / Command line / PowerShell):

```
python scan_crlf.py
```
